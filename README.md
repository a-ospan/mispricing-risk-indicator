# Mispricing Risk Indicator

Mispricing Risk Indicator built with U.S. financial data from 2015 to 2024, inspired by the IMF Working Paper **"Predicting Financial Crises: The Role of Asset Prices" (WP/23/157)**.

The indicator combines equity returns, volatility, exchange rates, treasury yields, sovereign spread conditions, and housing prices into a **0 to 100 risk score** to monitor potential asset pricing risk.

## Tools

Python, Pandas, NumPy, Matplotlib, Quarto, financial time series analysis, percentile scoring.

## Output

PDF, HTML and Quarto report files are available in the `report` folder.
